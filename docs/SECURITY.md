# 安全边界

这是为受信任本机插件提供的配置向导，不是多用户服务或插件沙箱。

服务仅绑定 127.0.0.1 的系统分配端口。数据 API 需要随机 256-bit bearer token，
检查 Host、Origin、Sec-Fetch-Site，POST 需要同源 Origin 与 application/json。
页面使用限制性 CSP、不加载外部脚本/字体/遥测，不支持任意命令或任意路径 API。

会话 URL 的 fragment 含 Token，不要放进模型上下文、远程日志或聊天。网页不会使用
localStorage 保存凭据。但浏览器/JS 的内存与历史不是加密存储，不能承诺安全擦除。
首次 GET 返回的静态页面不包含用户配置，配置 API 另外认证。

specFile 与 spec 都只能来自可信插件。保存位置由可信描述决定，网页不能改写任意目标。
保留键被拒绝，JSON Pointer 访问只查自身属性。路径校验拒绝明显遍历、别名子路径和硬链接。
跨进程校验存在 TOCTOU 边界，不对同用户恶意程序、管理员、内核或特殊文件系统提供隔离保证。

## 秘密

默认声明秘密而未允许明文保存会失败；显式 allowPlaintextSecrets:true 才能写 JSON。
访问权限不是加密。接口 result、网页初始值和日志不含已有秘密。
readConfig 是显式给受信任业务插件的读取 API，会包含配置中的秘密；调用者负责不回显。

Windows 使用系统 PowerShell 固定命令设置/校验 ACL，路径走环境变量，凭据不进入命令参数。
不运行下载的 .ps1、不更改执行策略。NTFS/ReFS 以外或组织策略限制时 fail closed。
POSIX 使用 0600 文件；权限仍不限制同 UID 的程序或 root。

## 崩溃与残留

正常结束会清理临时文件和 `<target>.config-guide.lock`。
SIGKILL、断电、进程崩溃可能留下锁或临时文件。
只有确认没有其他向导/写入进程时，才手动删除相应残留；不会按时间自动抢锁。
配置可能已经提交后才崩溃，不能依据“终端没有成功输出”就认定文件未修改。

本次交付没有进行第三方安全审计，也没有在 Windows/macOS 实机或真实 Jira 上完成验证。
附带的跨平台 CI 需要你推送仓库后运行，不等于已经验证过的平台。
