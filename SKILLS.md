# Repository skills

This repository ships one Codex-compatible skill:

- [`config-guides`](skills/config-guides/SKILL.md): generate and run a one-time local configuration guide, or implement an OpenCLI `<site> setup` command backed by `@zevaier/config-guides`.

When a request mentions generating a configuration guide, letting the owner complete configuration in a browser, or developing an OpenCLI setup command, read that skill before editing files or starting the guide. The skill is self-contained and does not require README context.
